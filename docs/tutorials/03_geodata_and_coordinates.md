## 1. В чём проблема и как спутники видят Землю?

Когда вы заказываете такси в приложении, вы вводите адрес словами (например, «Минск, ул. Притыцкого»).  
Но спутники дистанционного зондирования (**Copernicus Sentinel**), метеорологические агентства (**NASA**, **ECMWF**) и математические модели машинного обучения не знают человеческих названий. Для них поверхность планеты — это непрерывная координатная сетка.

Чтобы выгрузить спутниковые снимки или метеоданные над озером, программа должна сказать спутниковому API:
> *«Вырежи снимок для прямоугольника между 53.94° и 54.02° северной широты и 27.28° и 27.46° восточной долготы».*

## 2. Координатная система WGS-84 (Широта и Долгота)

Мировой общепринятый стандарт для спутников, GPS и картографии — **WGS-84** (в геоинформационных системах обозначается кодом `EPSG:4326`).

В этой системе любая точка на поверхности планеты описывается двумя числами:

### 2.1. Широта (Latitude, `lat`, математическая ось $Y$)
* Показывает смещение от экватора ($0^\circ$) к Северному полюсу ($+90^\circ$) или Южному полюсу ($-90^\circ$).
* **Диапазон для Беларуси:** от **$51.2^\circ\text{ с.ш.}$** (южная граница в районе Бреста/Гомеля) до **$56.2^\circ\text{ с.ш.}$** (северная граница Витебской области).

### 2.2. Долгота (Longitude, `lon`, математическая ось $X$)
* Показывает смещение от Гринвичского нулевого меридиана на восток ($+180^\circ$) или на запад ($-180^\circ$).
* **Диапазон для Беларуси:** от **$23.1^\circ\text{ в.д.}$** (западная граница у Бреста/Гродно) до **$32.8^\circ\text{ в.д.}$** (восточная граница у Хотимска).

---

### ⚠️ Ловушка №1 в геопрограммировании: «Порядок координат»

Это самая частая ошибка даже у опытных разработчиков:
* **В картографии и веб-картах (Leaflet, Google Maps):** пишут `[Широта, Долгота]` $\rightarrow$ `(lat, lon)` $\rightarrow$ `(Y, X)`.
* **В математике, GeoJSON и библиотеке Shapely:** пишут `[Долгота, Широта]` $\rightarrow$ `(lon, lat)` $\rightarrow$ `(X, Y)`.

> Если вы перепутаете их местами и пошлёте в спутниковый сервис `(27.38, 53.98)` вместо `(53.98, 27.38)`, спутник будет искать ваше Заславское водохранилище в Индийском океане у берегов Сомали!

## 3. Что такое Bounding Box (Ограничивающий прямоугольник)?

Спутниковые сканеры не умеют на лету вырезать из космоса извилистую береговую линию озера. Они выгружают данные прямоугольными фрагментами.  
Минимальный прямоугольник, в который целиком помещается водоём, называется **Bounding Box (BBox)**.

Он задаётся 4 числами:
$$\mathbf{BBox} = [min\_lon,\ min\_lat,\ max\_lon,\ max\_lat]$$
* $min\_lon$ — самая западная точка водоёма (левая граница);
* $min\_lat$ — самая южная точка водоёма (нижняя граница);
* $max\_lon$ — самая восточная точка водоёма (правая граница);
* $max\_lat$ — самая северная точка водоёма (верхняя граница).

### Пример из нашего файла `configs/water_bodies.yaml`:
Для Заславского водохранилища:
```yaml
bounding_box:
  min_lon: 27.2800  # Западная граница
  min_lat: 53.9400  # Южная граница
  max_lon: 27.4600  # Восточная граница
  max_lat: 54.0200  # Северная граница
```

## 4. Геометрия в Python: библиотека `Shapely`

Библиотека `shapely` — это индустриальный стандарт для векторной геометрии в Python.

### Установка:
```bash
.venv/bin/pip install shapely
```

### Основные геометрические объекты:
1. `Point(x, y)` — точка (например, станция мониторинга или сброса вод). *Помните: X=долгота, Y=широта!*
2. `Polygon([(x1, y1), (x2, y2), ...])` — многоугольник озера.
3. `box(minx, miny, maxx, maxy)` — удобный генератор прямоугольника Bounding Box.

### Практический пример: проверка попадания станции в акваторию озера (Spatial Query)
```python
from shapely.geometry import Point, box

# 1. Создаем прямоугольник BBox Заславского водохранилища
zaslav_box = box(minx=27.28, miny=53.94, maxx=27.46, maxy=54.02)

# 2. Создаем две тестовые точки:
# Точка А: гидропост в акватории Минского моря
station_in_lake = Point(27.380, 53.985)

# Точка Б: центр Минска (за пределами водоема)
station_in_city = Point(27.561, 53.904)

# 3. Проверяем принадлежность (метод .contains):
print("Станция на озере попадает в зону:", zaslav_box.contains(station_in_lake))
# Выведет: True

print("Точка в Минске попадает в зону:", zaslav_box.contains(station_in_city))
# Выведет: False

# 4. Расчет расстояния (в градусах):
distance = station_in_lake.distance(station_in_city)
print(f"Расстояние между точками: {distance:.4f} градусов")
```

## 5. Как геоданные используются в НАШЕМ курсовом проекте?

1. **В модуле `configs/water_bodies.yaml`:** хранятся центроиды и Bounding Box озер Беларуси.
2. **В модуле загрузки метеоданных (`download_meteo.py`):** координаты передаются в REST API NASA:  
   `params = {"latitude": 53.9850, "longitude": 27.3800}`.
3. **В веб-дашборде (`dashboard.html`):** Bounding Box используется для отрисовки полупрозрачных прямоугольных зон акваторий на карте Leaflet через `L.rectangle([[53.94, 27.28], [54.02, 27.46]])`.

## 6. Где практиковаться (Бесплатные интерактивные онлайн-инструменты)

* **[geojson.io](https://geojson.io/)** — **Главный инструмент разработчика геоданных.**  
  Откройте карту, найдите любое озеро в Беларуси (например, Нарочь), выберите инструмент «Прямоугольник» или «Полигон» и нарисуйте его. Справа вы увидите точные сгенерированные координаты вершин.
* **[bboxfinder.com](http://bboxfinder.com/)** — Самый быстрый способ выделить любую область на карте и скопировать её Bounding Box в один клик.
