## 1. Зачем нужен веб-фреймворк и REST API в курсовой работе?

К этому моменту в проекте уже реализованы все ключевые интеллектуальные компоненты:
1. Загрузка спутниковых и метеорологических данных.
2. Расчёт признаков и временных лагов.
3. Обученные модели градиентного бустинга (LightGBM).
4. Онтологический граф знаний и экспертные правила оценки риска (СанПиН РБ).

Но как эти результаты отдать внешнему миру?
- Пользователь, эколог или инспектор санэпиднадзора не будет открывать терминал Linux и запускать консольные Python-скрипты.
- Будущий веб-интерфейс (дашборд с интерактивной картой) должен как-то запрашивать актуальные данные и графики у сервера.
- Геопорталы государственных служб (например, геоинформационные системы Минприроды РБ) интегрируются с внешними модулями через **REST API**.

**REST API** позволяет любой внешней программе отправить стандартизированный HTTP-запрос (например, `GET /predict/BY_RES_001`) и мгновенно получить структурированный JSON-ответ с прогнозом и рекомендациями.

## 2. Почему именно FastAPI, а не Flask или Django?

| Критерий | Django | Flask | FastAPI |
| :--- | :--- | :--- | :--- |
| **Основное назначение** | Огромные монолиты с встроенной админкой и ORM | Простые микросервисы | Высокопроизводительные API и микросервисы |
| **Скорость работы** | Медленнее (WSGI) | Медленнее (WSGI) | Очень быстрая (ASGI, на базе Starlette/uvloop) |
| **Валидация типов** | Ручная или через Django Forms | Ручная (через marshmallow или if) | **Автоматическая «из коробки» (Pydantic)** |
| **Документация API** | Требует сторонних плагинов (drf-yasg) | Требует сторонних плагинов (flask-restx) | **Генерируется автоматически (`/docs` - Swagger)** |
| **Поддержка асинхронности** | Частичная | Ограниченная | **Нативная поддержка `async/await`** |

Для Data Science и ML-проектов **FastAPI** стал мировым индустриальным стандартом благодаря феноменальной скорости и лаконичности кода.

## 3. Что такое Pydantic и почему он неразрывно связан с FastAPI?

В обычном Python типы переменных носят рекомендательный характер (type hinting). Если функция ожидает число `float`, а клиент прислал строку `"тридцать"`, в стандартном коде программа выбросит необработанное исключение `TypeError` или `ValueError` и сервер упадет с ошибкой 500.

**Pydantic** — это библиотека для строгой валидации и сериализации данных на основе классов Python:
1. **Автоматический парсинг и приведение типов:** строка `"25.4"` автоматически станет числом `25.4`.
2. **Защита от некорректных данных:** если передано невалидное значение, Pydantic вернет клиенту понятную ошибку `422 Unprocessable Entity` с точным указанием ошибочного поля.
3. **Сериализация ответов (`response_model`):** гарантирует, что клиент получит только те поля и в том формате, которые заявлены в контракте API.

### Как схема объявлена в нашем проекте:
В [`src/api/main.py`](file:///home/frolov-pc/antigravity/water_eutrophication/src/api/main.py) мы описали строгую модель ответа для экспертного заключения:

```python
from typing import List
from pydantic import BaseModel

class AlertResponse(BaseModel):
    water_body_id: str
    water_body_name: str
    assessment_date: str
    forecast_horizon_days: int
    predicted_chl_a_ug_l: float
    bloom_probability: float
    trophic_index_tsi: float
    trophic_class: str
    alert_level: str                # GREEN, YELLOW, RED
    reasons: List[str]              # Список аргументов экспертной системы
    recommended_actions: List[str]  # Список регламентных мер
```

## 5. Автоматическая интерактивная документация (Swagger UI)

Огромное преимущество FastAPI, которое производит сильное впечатление на защите курсовых и дипломных проектов — **встроенный Swagger UI**.

При запуске сервера FastAPI автоматически генерирует спецификацию **OpenAPI** и интерактивный веб-интерфейс, доступный по адресу:
$$\text{http://localhost:8000/docs}$$

### Что дает Swagger UI:
1. Полное интерактивное описание всех эндпоинтов, их параметров и схем ответов.
2. Кнопка **«Try it out»**: комиссия или разработчик может прямо в браузере ввести `water_body_id = BY_RES_001`, нажать **Execute** и увидеть реальный HTTP-запрос `curl`, заголовки и JSON-ответ со статусом 200 OK.
3. Альтернативная документация ReDoc доступна по адресу `http://localhost:8000/redoc`.
