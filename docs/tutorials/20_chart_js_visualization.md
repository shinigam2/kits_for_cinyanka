## 1. Зачем нужна визуализация временных рядов в курсовом проекте?

В нашей курсовой работе система не просто выдает одиночную цифру прогноза, а анализирует долгосрочные гидроэкологические процессы за несколько лет (2020–2025 гг.).

Человеческий мозг плохо воспринимает сухие столбцы чисел в таблицах или базы данных Parquet:
- Инспектору Минприроды РБ или членам экзаменационной комиссии на защите нужно наглядно увидеть **динамику и сезонный тренд**: в какие месяцы хлорофилл-а находится на безопасном уровне, а когда наступает резкий взрывной рост биомассы фитопланктона.
- График наглядно демонстрирует фундаментальное экологическое различие наших двух пилотных объектов:
  1. **Заславское водохранилище (Минское море):** мелководный эвтрофный водоём, где в июле–августе концентрация хлорофилла-а регулярно пробивает опасный санитарный порог в $25\text{–}40\ \text{мкг/л}$.
  2. **Озеро Нарочь:** глубоководный олиго-/мезотрофный водоём, где концентрация остаётся стабильно низкой ($4\text{–}12\ \text{мкг/л}$) даже в самые жаркие недели лета.

Для отображения графиков в веб-приложениях стандартом является библиотека **Chart.js**.

## 2. Почему Chart.js, а не статичные картинки из Matplotlib?

| Критерий | Matplotlib / Seaborn (PNG) | Chart.js (HTML5 Canvas) |
| :--- | :--- | :--- |
| **Формат** | Статичная растровая картинка (`.png`) | Векторный интерактивный рендеринг в браузере |
| **Интерактивность** | Нет (нельзя навести мышь или кликнуть) | **Да:** анимация появления, всплывающие подсказки (Tooltips) с точными значениями при наведении |
| **Управление легендой** | Статичный текст | **Кликабельная легенда:** можно в один клик скрыть/показать любой водоём |
| **Адаптивность** | Фиксированное разрешение в пикселях | Автоматически масштабируется под экраны любых смартфонов, планшетов и проекторов |
| **Нагрузка на сервер** | Сервер тратит процессорное время на генерацию картинок | **Нулевая нагрузка:** график отрисовывается на видеокарте/процессоре клиента через Canvas API |

## 3. Архитектура и реализация графика в нашем проекте (`generate_dashboard.py`)

В генераторе дашборда [`src/api/generate_dashboard.py`](file:///home/frolov-pc/antigravity/water_eutrophication/src/api/generate_dashboard.py) и готовом файле [`dashboard.html`](file:///home/frolov-pc/antigravity/water_eutrophication/data/processed/dashboard.html) график реализован следующим образом:

### 1. Разметка HTML и контейнер Canvas
Chart.js рисует графику внутри элемента `<canvas>`. Чтобы график корректно масштабировался, его оборачивают в относительный контейнер:
```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>

<div class="chart-container" style="position: relative; height: 340px; width: 100%;">
    <canvas id="timeSeriesChart"></canvas>
</div>
```

### 2. Подготовка и передача данных из Python в JavaScript
В Python даты и концентрации хлорофилла-а сериализуются в JSON-массивы:
```python
import json

# zaslav_dates: ["2024-05-01", "2024-05-11", ...]
# zaslav_chla:  [12.4, 18.2, 34.5, ...]
# naroch_chla:  [4.1, 5.2, 7.8, ...]
```

### 3. Конфигурация графика: несколько линий и санитарный порог
```javascript
const ctx = document.getElementById('timeSeriesChart').getContext('2d');

new Chart(ctx, {
    type: 'line', // Линейный график временного ряда
    data: {
        labels: ["2024-05-01", "2024-05-11", ...], // Ось X (даты спутниковых съёмок)
        datasets: [
            // Линия 1: Заславское водохранилище
            {
                label: 'Заславское вдхр. (Chl-a, мкг/л)',
                data: [12.4, 18.2, 34.5, ...],
                borderColor: '#ef4444',              // Красный цвет тревоги
                backgroundColor: 'rgba(239, 68, 68, 0.1)', // Легкая полупрозрачная подсветка под кривой
                tension: 0.3,                        // Плавное сглаживание кривой (кубический сплайн)
                borderWidth: 2
            },
            // Линия 2: Озеро Нарочь
            {
                label: 'Озеро Нарочь (Chl-a, мкг/л)',
                data: [4.1, 5.2, 7.8, ...],
                borderColor: '#38bdf8',              // Голубой цвет чистой воды
                backgroundColor: 'rgba(56, 189, 248, 0.1)',
                tension: 0.3,
                borderWidth: 2
            },
            // Линия 3: Горизонтальный нормативный порог СанПиН (25 мкг/л)
            {
                label: 'Порог цветения (25 мкг/л)',
                data: new Array(datesCount).fill(25.0), // Массив константных значений 25.0
                borderColor: '#eab308',              // Желтая линия предупреждения
                borderDash: [5, 5],                  // Пунктирная линия
                borderWidth: 1.5,
                pointRadius: 0                       // Без точек на изгибах
            }
        ]
    },
    options: {
        responsive: true,
        maintainAspectRatio: false, // Разрешаем графику заполнять высоту родительского блока
        scales: {
            y: {
                title: { display: true, text: 'Хлорофилл-a (мкг/л)', color: '#94a3b8' },
                grid: { color: '#334155' },          // Темная сетка для темной темы дашборда
                ticks: { color: '#94a3b8' }
            },
            x: {
                grid: { color: '#1e293b' },
                ticks: {
                    color: '#94a3b8',
                    maxTicksLimit: 10                // Прореживание подписей дат, чтобы они не слипались
                }
            }
        },
        plugins: {
            legend: {
                labels: { color: '#f8fafc' }         // Белый цвет надписей легенды
            }
        }
    }
});
```

## 4. Что этот график демонстрирует на защите курсовой?

1. **Мгновенное сравнение двух гидроэкосистем:**  
   Комиссия сразу видит, как кривая Заславского водохранилища (красная) в июле пересекает пунктирную желтую линию порога 25 мкг/л — именно в этот момент система выставляет статус опасности `RED`.  
   Кривая озера Нарочь (голубая) весь сезон стабильно держится на дне графика (в пределах 4–8 мкг/л), подтверждая его статус жемчужины белорусской природы.
2. **Интерактивное управление:**  
   Прямо во время презентации можно кликнуть в легенде по надписи *«Озеро Нарочь»* — и график изолирует только Минское море, пересчитав масштаб оси Y.
3. **Точность до десятых долей:**  
   При наведении курсора на любой пик всплывает окно Tooltip с точной датой и значением концентрации из модели.
