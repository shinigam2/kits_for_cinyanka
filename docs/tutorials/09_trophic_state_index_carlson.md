## 1. Что такое эвтрофикация и почему это экологическая катастрофа?

Слово «эвтрофия» в переводе с греческого означает «хорошее питание».  
Но в экологии **эвтрофикация** — это процесс деградации водоёма из-за чрезмерного поступления биогенных веществ (в первую очередь **фосфора** и **азота**) со сточными водами, смывами с сельхозугодий и дачных поселков:

$$\text{Смыв фосфора/азота} \longrightarrow \text{Взрывной рост водорослей} \longrightarrow \text{Покрытие поверхности пленкой} \longrightarrow \text{Гибель рыбы и токсины}$$

### Цепочка разрушения водоёма:
1. Водоросли и цианобактерии получают избыток «пищи» и тепла и начинают лавинообразно делиться.
2. Прозрачность воды падает до нуля (мутность зашкаливает). Солнечный свет перестает проникать на дно, придонная растительность погибает.
3. Биомасса водорослей отмирает и оседает на дно.
4. Бактерии-деструкторы начинают разлагать эту мертвую биомассу, **жадно поглощая весь растворенный в воде кислород**.
5. Наступает **замор рыбы** (аноксия), а цианобактерии (сине-зелёные водоросли) выделяют опасные нервно-паралитические и печеночные яды — **микроцистины (цианотоксины)**.

## 2. Индекс трофического состояния Карлсона (Carlson's TSI)

В 1977 году американский лимнолог Роберт Карлсон (Robert Carlson) предложил единую стандартизированную математическую шкалу от $0$ до $100$ для оценки степени эвтрофикации озер — **Trophic State Index (TSI)**.

Поскольку рост биомассы водорослей происходит экспоненциально, формула Карлсона является **логарифмической**:

$$\mathbf{TSI}(Chl) = 9.81 \cdot \ln(Chl\text{-}a) + 30.6$$

где:
* $Chl\text{-}a$ — концентрация хлорофилла-a в воде (мкг/л, $\mu g/L$);
* $\ln$ — натуральный логарифм.

---

## 3. Четыре классических класса трофности водоемов

Шкала TSI делит озера на 4 строгих класса:

| Класс трофности | Диапазон TSI | Концентрация Chl-a | Характеристика и экологический статус |
| :--- | :---: | :---: | :--- |
| **1. Олиготрофный** | $\mathbf{TSI < 40}$ | $< 2.6\text{ мкг/л}$ | Кристально чистая, холодная вода, прозрачность $>4\text{ м}$, очень мало биогенов. Цветение исключено. |
| **2. Мезотрофный** | $\mathbf{40 \le TSI < 50}$ | $2.6 - 7.3\text{ мкг/л}$ | Умеренная продуктивность, прозрачность $2-4\text{ м}$. Здоровое состояние (наше **озеро Нарочь**). |
| **3. Эвтрофный** | $\mathbf{50 \le TSI \le 70}$ | $7.3 - 56.0\text{ мкг/л}$ | Высокая биогенная нагрузка, частые вспышки водорослей летом, мутная вода (наше **Заславское водохранилище**). |
| **4. Гиперэвтрофный** | $\mathbf{TSI > 70}$ | $> 56.0\text{ мкг/л}$ | Катастрофическое цветение («зелёный суп»), токсичность, заморные явления, купание запрещено. |

## 4. Реализация на Python в НАШЕМ курсовом проекте

В файле `water_eutrophication/src/knowledge_graph/graph_engine.py` расчет индекса Карлсона и классификация автоматизированы:

```python
import math

def calculate_carson_tsi(chl_a: float) -> float:
    """Расчет TSI Карлсона с защитой от нулевых значений."""
    if chl_a <= 0.1:
        return 0.0
    return round(9.81 * math.log(chl_a) + 30.6, 1)

# Пример: проверка для Заславского водохранилища летом (Chl-a = 32.3 мкг/л)
tsi_zaslav = calculate_carson_tsi(32.3)
print(f"TSI Заславского: {tsi_zaslav}")  # Выведет: 64.7 (Эвтрофный статус!)

# Пример: проверка для озера Нарочь летом (Chl-a = 5.2 мкг/л)
tsi_naroch = calculate_carson_tsi(5.2)
print(f"TSI Нарочи: {tsi_naroch}")       # Выведет: 46.8 (Мезотрофный статус!)
```

## 5. Зачем это нужно для Графа знаний и Санитарных правил РБ?

Сам по себе прогноз ML («завтра будет 32 мкг/л хлорофилла») бесполезен для министра экологии или санврача.  
Но когда система переводит это число через формулу Карлсона в вердикт:
> *«Водоём переходит в эвтрофное состояние (TSI = 64.7). Риск выделения цианотоксинов. Требуется внеплановый отбор проб санэпиднадзором Минского района».*

Система становится настоящей **системой поддержки принятия решений (Decision Support System / DSS)**.
