## 1. Что такое Pandas и почему обычный Python или Excel не подходят?

В базовом Python для хранения таблиц обычно используют список словарей:
```python
# Базовый Python: медленно и неудобно для анализа
data = [
    {"date": "2025-07-01", "temp": 22.4, "chl_a": 15.2},
    {"date": "2025-07-02", "temp": 24.1, "chl_a": 18.0},
]
```
Если у вас 1 000 строк — это работает. Но когда у вас 100 000 строк метеоданных, спутниковых измерений и датчиков, стандартные циклы `for` в Python начинают тормозить.

**Библиотека Pandas** написана на языке C. Она оперирует столбцами как едиными непрерывными блоками памяти.  
Любая операция (например, перевести миллион значений температуры из Фаренгейтов в Цельсии) выполняется **векторизованно** — мгновенно для всего столбца сразу, без медленных циклов Python!

## 2. Анатомия Pandas: две главные структуры

1. **`Series` (Одномерный массив):**  
   Один отдельный столбец данных с индексом (например, только столбец температур).
2. **`DataFrame` (Двумерная таблица):**  
   Полноценная таблица, состоящая из нескольких столбцов-Series, объединенных общим индексом строк.

```python
import pandas as pd

# Создание DataFrame вручную:
df = pd.DataFrame({
    "date": ["2025-07-01", "2025-07-02", "2025-07-03"],
    "temp": [22.4, 25.1, 19.8],
    "chl_a": [14.0, 26.5, 12.3]
})
```

Когда данные загружены из файла или API, профессионал всегда выполняет 3 быстрых команды:


## 4. Очистка и фильтрация данных (Булевы маски)

### 4.1. Фильтрация строк
Чтобы отобрать только те дни, когда температура была выше 20°C, в Pandas не пишут цикл `for`. Пишут **булеву маску**:
```python
# Возвращает True/False для каждой строки
mask = df["temp"] >= 20.0

# Передаем маску в квадратные скобки датафрейма:
hot_days = df[mask]
print(hot_days)
```

### 4.2. Борьба с пропусками и спецкодами (Специфика NASA)
Метеорологические спутники NASA обозначают отсутствие данных числом `-999.0` (например, прибор отключился или датчик дал сбой).  
Если посчитать среднюю температуру с таким значением, мы получим абсурдные $-300^\circ\text{C}$!

Как мы фильтруем это в коде:
```python
# Заменяем аномальные значения на пустые (NaN - Not a Number):
df.loc[df["temp"] <= -900, "temp"] = None

# Либо отфильтровываем только валидные строки:
valid_df = df[df["temp"] > -900]
```

## 5. Работа с датами и временными рядами (`pd.to_datetime`)

По умолчанию даты из файлов и API приходят как обычные текстовые строки (`object` / `string`), например `"2025-07-21"`. Для Python это просто набор символов.

### 5.1. Преобразование в специальный тип времени:
```python
df["date"] = pd.to_datetime(df["date"])
```

### 5.2. Магический аксессор `.dt`
После преобразования у столбца появляется свойство `.dt`, открывающее доступ к календарным атрибутам:
```python
# Извлечение месяца (число от 1 до 12):
df["month"] = df["date"].dt.month

# День года (от 1 до 365) - критичен для сезонных моделей ML:
df["day_of_year"] = df["date"].dt.dayofyear

# День недели (0 - понедельник, 6 - воскресенье):
df["day_of_week"] = df["date"].dt.dayofweek
```

### 5.3. Фильтрация декадных спутниковых дат (Пример из Copernicus)
Спутники Copernicus LWQ делают снимки трижды в месяц: 1-го, 11-го и 21-го числа.  
Как отобрать только эти даты одной строчкой:
```python
# Отбираем только 1, 11 и 21 числа любого месяца:
decadal_df = df[df["date"].dt.day.isin([1, 11, 21])]
```

## 6. Как Pandas используется в НАШЕМ курсовом проекте?

1. **В `download_meteo.py`:**  
   Скрипт собирает 2 192 записи JSON от NASA в структурированный DataFrame, преобразует даты и сохраняет в единый массив:
   ```python
   df = pd.DataFrame(records)
   df["date"] = pd.to_datetime(df["date"])
   ```
2. **В `satellite_processor.py`:**  
   Используется выборка по дням месяца (`.dt.day.isin([1, 11, 21])`) для моделирования декадных спутниковых циклов.
3. **В `build_features.py`:**  
   С помощью временных срезов извлекаются погодные окна за 7, 14 и 21 день до текущей даты:
   ```python
   # Извлекаем погоду строго за 14 дней до даты спутникового снимка:
   m_window_14 = sub_m.loc[cur_date - pd.Timedelta(days=14):cur_date]
   temp_mean_14d = m_window_14["T2M"].mean()
   ```
