# Технология №19: Leaflet.js и Web-ГИС картография (Интерактивные спутниковые карты водоёмов Беларуси)

---

## 1. Зачем нужна Web-ГИС картография в курсовом проекте?

Тема нашей курсовой работы — **«Интеллектуальная система мониторинга, прогнозирования и раннего предупреждения риска эвтрофикации водных объектов»** (на примере Заславского водохранилища и озера Нарочь).

Любой экологический и гидрологический мониторинг неразрывно связан с пространством:
- Водоёмы имеют точные географические координаты (широту и долготу в системе WGS-84);
- Цветение сине-зеленых водорослей распространяется по конкретной акватории;
- Инспектор санэпиднадзора или отдыхающий на пляже должен наглядно видеть карту: где именно находится водный объект, каковы его границы и какой уровень угрозы присвоен акватории (красный предупреждающий маркер `RED` на Минском море или нормальный статус на озере Нарочь).

Для создания карт в веб-приложениях существует открытый индустриальный стандарт — библиотека **Leaflet.js**. Она невероятно легковесна (всего ~42 КБ), работает на любых устройствах и не требует платных API-ключей (в отличие от Google Maps).

## 2. Как устроена цифровая картография: тайловые слои (Tile Layers)

Карта мира не передается в браузер одной огромной картинкой (она весила бы терабайты). Вместо этого вся поверхность Земли нарезается на миллиарды квадратных фрагментов размером $256 \times 256$ пикселей — **тайлов (tiles)**.

URL тайлового сервера строится по стандартному шаблону:
$$\text{https://tile-provider.com/}\{z\}/\{x\}/\{y\}\text{.png}$$
- **$z$ (zoom)** — уровень приближения (от $0$ — вся планета, до $18$ — отдельные дома и пирсы);
- **$x, y$** — координаты конкретного квадрата на сетке проекции Меркатора (Web Mercator EPSG:3857).

Когда пользователь перемещает карту или крутит колесо мыши, Leaflet мгновенно вычисляет, какие именно квадраты попадают в экран, и загружает только их.

### Базовые подложки в нашем дашборде:
В файле дашборда [`data/processed/dashboard.html`](file:///home/frolov-pc/antigravity/water_eutrophication/data/processed/dashboard.html) мы подключили три типа карт:
1. **Спутниковые снимки высокого разрешения Esri World Imagery:**
   - Позволяют визуально оценить реальную водную гладь, острова и прибрежные зоны водохранилищ из космоса.
2. **Схематическая векторная подложка OpenStreetMap (OSM):**
   - Отображает названия населенных пунктов, дороги, пляжи и санатории Минского района и Мядельщины.
3. **Топографическая гидрологическая карта Esri Topo:**
   - Показывает рельеф местности и водосборные бассейны рек (Свислочь, Нарочанка).

## 3. Архитектура и код карты в нашем дашборде

Генератор дашборда [`src/api/generate_dashboard.py`](file:///home/frolov-pc/antigravity/water_eutrophication/src/api/generate_dashboard.py) формирует автономный HTML-документ со следующей структурой:

### 1. Подключение библиотеки и стилей (CDN)
```html
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>

<!-- Важно: контейнеру карты в CSS ВСЕГДА нужно задавать явную высоту! -->
<div id="map" style="height: 380px; width: 100%; border-radius: 8px;"></div>
```

### 2. Инициализация карты и центрирование на Беларуси
Центральная точка $[54.42, 27.10]$ выбрана так, чтобы в поле зрения одновременно попадали и Минское море, и озеро Нарочь на зуме 8:
```javascript
const map = L.map('map', {
    center: [54.42, 27.10],
    zoom: 8,
    scrollWheelZoom: true
});
```

### 3. Подключение слоев и контроллера переключения
```javascript
// Спутниковый слой Esri
const esriSatellite = L.tileLayer(
    'https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}',
    { maxZoom: 18, attribution: 'Tiles &copy; Esri World Imagery' }
);

// Слой OpenStreetMap
const osmLayer = L.tileLayer(
    'https://tile.openstreetmap.org/{z}/{x}/{y}.png',
    { maxZoom: 18, attribution: '&copy; OpenStreetMap contributors' }
);

// Активируем спутник по умолчанию
esriSatellite.addTo(map);

// Добавляем переключатель слоев в правый верхний угол
const baseMaps = {
    "🛰️ Спутник (Esri Imagery)": esriSatellite,
    "🗺️ OpenStreetMap": osmLayer
};
L.control.layers(baseMaps, null, { position: 'topright' }).addTo(map);
```

### 4. Отрисовка границ акваторий водоёмов (Bounding Box)
С помощью `L.rectangle` мы наносим географические границы полигонов, для которых агрегировались спутниковые данные Sentinel-2:
```javascript
// Координаты границ Заславского водохранилища: [[Юг, Запад], [Север, Восток]]
const zaslavBounds = [[53.94, 27.28], [54.02, 27.46]];
L.rectangle(zaslavBounds, {
    color: "#ef4444",       // Красная тревожная рамка
    weight: 2,
    fillColor: "#ef4444",
    fillOpacity: 0.25,
    dashArray: "4, 4"       // Пунктирная граница
}).addTo(map).bindTooltip("Акватория: Заславское вдхр.");
```

### 5. Интерактивные маркеры со статусом риска и всплывающими окнами (Popup)
В центр водоёма помещается круглый маркер `L.circleMarker`, цвет которого отражает уровень угрозы:
```javascript
const m1 = L.circleMarker([53.985, 27.380], {
    radius: 12,
    color: '#ffffff',
    fillColor: '#ef4444',   // Красный сигнал тревоги
    fillOpacity: 0.95
}).addTo(map);

// При клике на маркер открывается карточка с прогнозом
m1.bindPopup(`
    <div style="color: #0f172a; min-width: 200px;">
        <h4 style="margin: 0; color: #dc2626;">Заславское вдхр. (Минское море)</h4>
        <b>Статус:</b> <span style="color: #dc2626;">RED (Высокий риск)</span><br>
        <b>Прогноз Chl-a:</b> 34.5 мкг/л<br>
        <b>Вероятность цветения:</b> 88.0%<br>
        <b>Глубина:</b> 3.5 м (мелководное)
    </div>
`);
```

## 4. Подводные камни и их решение в нашем коде

1. **Эффект «Серой сетки» (Grey Tiles Issue):**  
   Если карта размещена внутри гибкого CSS-контейнера (`CSS Grid` или вкладки), библиотека Leaflet в момент инициализации может не успеть определить точные пиксельные размеры экрана. В результате тайлы не подгружаются, и пользователь видит серые квадраты.  
   **Решение:** вызов специального метода `map.invalidateSize()` после загрузки страницы:
   ```javascript
   setTimeout(() => { map.invalidateSize(); }, 300);
   ```

2. **Ограничения протокола `file://` и Referer Policy:**  
   Некоторые бесплатные картографические серверы (например, CartoDB Positron) блокируют запросы, если HTML-страница открыта локально с диска (`file:///...`). Серверы **Esri ArcGIS** и **OpenStreetMap** стабильно работают как локально, так и на удаленном сервере без блокировок.

## 6. Контрольный мини-вопрос для проверки

> **Ситуация:**  
> Разработчик создал на странице блок `<div id="map"></div>` и написал JavaScript-код инициализации `L.map('map')`. Однако в браузере карта вообще не отображается, хотя в консоли нет ошибок.  
>
> **Вопрос:**  
> Какую типичную ошибку начинающих допустил разработчик в стилях CSS?  
> 1) Забыл подключить jQuery?  
> 2) Не задал явную высоту контейнеру карты (например, `height: 400px`), из-за чего по умолчанию блок имеет высоту 0 пикселей?  
> 3) Использовал недопустимый браузер?
